# Logos

The brand mark is the shield from the site header (`.brand__mark`).

- `favicon.svg`: the white shield (`color-on-accent`) on a rounded `color-accent` square. It is the browser tab icon on every page. The colors are fixed to the light theme values.
- `apple-touch-icon.png`: 180 × 180, the same mark with square corners, because iOS rounds them itself. It is used when the site is saved to a home screen.

There is no wordmark. The site name is set in plain type next to the mark ("Privacy Policies" / "Privatlivspolitikker").
