# Hero

The intro at the top of the front page: the page's single `h1` and one lead paragraph.

- Markup: `section.hero > h1.hero__title + p.hero__lead`.
- The title is `page-title-mobile` below 640px and `page-title` from 640px. The lead is `lead` in `color-text-muted`, no wider than `content-width`.
- Use it only on the front page. Policy pages use PolicyHeader.
