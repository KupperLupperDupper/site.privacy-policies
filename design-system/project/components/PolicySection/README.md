# PolicySection

One topic of a privacy policy: a heading followed by plain paragraphs, lists and links.

- Markup: `section.policy-section > h2.policy-section__title`, followed by plain `p`, `ul` and `a` elements, which are styled automatically.
- Sections are separated by a `color-border` hairline. Contact is always the last section.
- Put the sections inside `article.policy`, after the Summary.
