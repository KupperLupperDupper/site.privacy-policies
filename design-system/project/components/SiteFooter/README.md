# SiteFooter

The footer on every page, with the contact email and the copyright line.

- Markup: `footer.site-footer > div.container.site-footer__inner` with two `span` elements.
- The contact text is "Questions?" in English and "Spørgsmål?" in Danish, followed by a `mailto:` link.
- Text is `small` in `color-text-muted`. The footer is stacked on mobile and becomes one row from 640px.
